# 🌡️ Logic Programming 2: Temperature Converter

A dynamic system built in JavaScript focused on sequential processing, strict input validation, and variable manipulation for mathematical conversions.

## 🎯 Objective
This interactive project aks the user for a temperature in Celsius degrees and outputs its exact equivalent in the Fahrenheit and Kelvin scales. The program implements an iterative flow control that strictly evaluates the input data type.

## ✨ Key Features
* **Data Validation:** Includes conditional logic to ensure the input is numeric (`number`) type, preventing the execution of text strings or null values.
* **Iterative Flow Control:** Uses loops to keep the program actively running in case of an invalid input, guiding the user toward the correct format without breaking the application's execution.
* **Mathematical Precision:** Applies formulas:
  * Fahrenheit: `(°C × 9/5) + 32`
  * Kelvin: `°C + 273.15`
* **Immediate Feedback:** Delivers the output through the DOM.

## 🛠️ Technologies Used
* **JavaScript (ES6+)**: Core logic, flow control, and data manipulation.
* **HTML5**: Base structure for browser deployment (DOM).
